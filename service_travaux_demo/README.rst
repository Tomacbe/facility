Données de démonstration pour FACILITY, fondées sur une maquette de la Commune de Rixensart : organigramme (services Voirie et Bâtiment, contremaîtres, brigadiers, équipes), agents, demandes avec photos avant et après, et douze mois d'historique fictif.

Toutes les personnes et les demandes sont fictives. Ce module sert aux démonstrations et aux tests : il ne doit pas être installé sur une base de production.


Utilisation
===========

Installer le module sur une base de test. Il installe FACILITY et charge les données. Pour recréer en une fois une base complète (FACILITY, démonstration et carte), voir le script creer_base_test.sh à la racine du dépôt.
